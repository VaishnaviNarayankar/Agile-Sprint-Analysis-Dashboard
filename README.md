
# Agile Sprint Analysis Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze Agile sprint performance, monitor task progress, and evaluate project execution. The project combines Excel VBA automation, Azure DevOps work-item management, and Power BI reporting to streamline sprint planning, task tracking, and performance analysis.

## Project Objectives
- Automate the creation of Agile work items in Azure DevOps.
- Organize project activities through Epics, Features, User Stories, and Tasks.
- Assign work items to respective team members.
- Monitor sprint-wise task progress and completion.
- Identify delayed and pending tasks.
- Evaluate sprint performance using key Agile metrics.
- Generate actionable insights for better project monitoring and decision-making.

## Data Integration & Automation

- **Raw Data Preparation:** Worked with an Excel file containing project work items, including Epics, Features, User Stories, Tasks, and their respective assignees.
- **VBA-Based Automation:** Developed Excel VBA code to automate the import of work-item data from Excel into Azure DevOps.
- **Azure DevOps Integration:** Automated the creation of corresponding work items in Azure DevOps, reducing manual data entry and streamlining project setup.
- **Work Item Assignment:** Incorporated responsible team members into the work-item creation process to establish task ownership and accountability.
- **Power BI Reporting:** Used the Azure DevOps project data to develop an interactive dashboard for sprint performance monitoring and analysis.

## Key Insights

- **Sprint Performance Overview:** Provides an overview of total tasks, completed tasks, delayed tasks, and pending tasks.

- **Sprint Completion Rate:** Measures the percentage of completed tasks against the total assigned tasks.

- **Sprint Success Rate:** Evaluates sprint performance based on defined success criteria.

- **Task Delay Analysis:** Tracks delayed tasks and analyzes delay rates to identify potential bottlenecks.

- **Average Tasks per Sprint:** Analyzes the average number of tasks assigned across sprints.

- **Sprint-wise Performance:** Compares task completion and progress across different sprints.

- **Task Status Distribution:** Visualizes task distribution across Completed, In Progress, Pending, and Delayed statuses.
